# Agent Rules & Versioning Guidelines

## Versioning Rules
- **Current Base Version**: Version 1.0 (v1.0.0)
- **Increment Policy**: Every subsequent feature modification, update, or code adjustment requested by the user MUST increment the version number as `Version 1.1`, `Version 1.2`, ..., `Version 1.n`.
- **Major Version Bump**: Do NOT bump to `Version 2.0` unless explicitly instructed by the user.
